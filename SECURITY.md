# Política de seguridad

## Informar de una vulnerabilidad
No abras un issue público. Usa *Security → Report a vulnerability* de este repositorio (aviso privado).

## Secretos
Nunca subas claves, tokens ni `.env`. Usa `.env.example` como plantilla. Si se filtra un secreto, revócalo y rótalo de inmediato.

## Versiones con soporte
La rama `main` y la última release etiquetada.
